# 🏥 2026 장기요양보험 수가 안내 & 본인부담금 계산기

> 보건복지부 고시 기준 장기요양보험 급여 종류별 수가표 조회 및 어르신 맞춤 본인부담금 실시간 시뮬레이션 웹 서비스입니다.

---

## 📌 주요 기능

1. **2026년 장기요양 급여 종류별 수가표 조회 (상단 탭)**
   * **재가급여 월 한도액**: 1~5등급 및 인지지원등급별 국가 지원 한도금액 표출
   * **방문요양 수가표**: 1회 이용 시간별(30분~240분) 총 급여비용 및 본인부담금 표출
   * **시설급여(요양원) 수가표**: 등급별 1일 수가 및 30일 이용 시 본인부담금 표출

2. **맞춤 본인부담금 시뮬레이터 (하단 계산기)**
   * 등급, 본인부담율(일반 15%, 감경 9%/6%, 수급자 0%), 서비스 종류, 이용일수를 입력받아 실시간 계산
   * **계산 항목**: 총 급여비용, 공단 부담금(국가 지원), 실제 내야 할 본인부담금, 남은 한도액

---

## 🛠 기술 스택 (Tech Stack)

* **Frontend**: HTML5, JavaScript (ES6+), Tailwind CSS (CDN)
* **Backend**: Node.js, Express.js, CORS
* **Data**: 2026년 보건복지부 공식 고시 기준 Mock Data
